# CLAUDE.md — outlayer-skills

This repository is what an AI agent reads to use OutLayer. It is served as-is at
`https://skills.outlayer.ai/<skill>/SKILL.md` (agents fetch it over HTTP) and
installed as-is into Claude Code and other harnesses (agents read it from disk).
Every line here is an instruction some model will follow with money on the line.
Write for a small-context model that reads only what it is pointed at.

## Layout — invariants

- One directory per skill, `SKILL.md` inside, YAML frontmatter with `name` and
  `description`. `build.sh` finds skills by that file; nothing lists them by hand
  except `outlayer/SKILL.md`, the entry skill.
- `SKILL.md` is ≤500 lines and ≤3 000 words. It holds what every task in that
  skill needs, plus a router table "the task in front of you → read THIS file".
  Everything else lives in `references/`, one file per job, loaded only when
  the job comes up. A reference may be long; `SKILL.md` may not.
- Links are relative (`references/x.md`). The router states the HTTP base once
  so a fetched copy still resolves. A reference starts with a one-line
  preamble naming its skill and that base.
- **One fact, one skill.** A reference is part of its skill and is served on
  the site, so it may not restate another skill. Where a topic is owned by a
  different skill, link its URL — `https://skills.outlayer.ai/<skill>/SKILL.md`.
- `web-ui/public/` is generated by `web-ui/build.sh`. Never commit it.

## After a product change

Do this whenever an endpoint, field, error code, limit, price, header or
behaviour changes in the coordinator, the contract, a connector or the CLI.

1. **Name the facts that changed**, one per line: `POST /wallet/v1/x` gained
   field `y`; refusal `z` is now terminal; the limit is 16 not 10. A change you
   cannot state as a fact is not ready to be documented.
2. **Read the code, not memory.** The handler in the coordinator
   (`src/handlers/`), the contract method, the connector's own README or
   `docs/CONNECTORS.md`. Copy field names, status strings and error codes from
   there verbatim. Never invent a name, a default or a limit; if the code does
   not say, ask.
3. **Find every mention.** `grep -rn '<old spelling>' --include='*.md' .` A fact
   is usually echoed in `api-index.md` and in one connector skill's example.
   Fix all of them or none.
4. **Edit the owner file** (table above) to the final state:
   - a new endpoint → its job's reference, plus a row in `api-index.md`'s endpoint table;
   - a new error / `reason` → `api-index.md`'s error table; a `/call` reason also goes in `outlayer-connectors` "Reading a refusal";
   - a new job that fits no reference → a new `references/<job>.md` and a router row;
   - a new thing an agent might ask for → the skill's `description`;
   - a new connector → its own `<name>-connector/SKILL.md`, a row in `outlayer-connectors` "The library", a row in `outlayer/SKILL.md`;
   - a new skill → its directory and a row in `outlayer/SKILL.md`.
5. **Do not append to `SKILL.md`** because it is the file you have open. If the
   fact is not needed by every task in the skill, it belongs in a reference.
6. Run `scripts/check.sh`. It fails on: a `SKILL.md` over the limits, a broken
   relative link, an orphan reference, a skill missing from `outlayer/SKILL.md`,
   a build error.
7. Leave the tree uncommitted and suggest a commit message. The owner commits,
   pushes and deploys.

## Writing rules

- **Final state only.** No "previously", "used to", "now supports", "as of".
  Git is the history.
- **Mirror the upstream API.** Field names, enum spellings and error codes
  exactly as the code emits them, lower/upper case included. When a set is
  exhaustive (status values, refusal codes), say so and list it whole — a model
  that is told "and others" invents the others.
- **Say what to do, then why in one clause.** Imperative, verb first. Tables of
  exact values beat prose.
- **Every example is runnable on mainnet** with `https://api.outlayer.ai`;
  testnet is "substitute the host" said once in Configuration, not repeated per
  example. Amounts are strings in minimal units; say the decimals.
- **No real credential, ever** — not a key, not a token, not a payment key,
  not in an example, not in a comment. Placeholders are `$API_KEY`, `wk_…`,
  `<base58_signature>`. A leaked value is rotated, not edited out.
- **What the agent must tell the user, and how**: when a step needs a human
  (a signature, money, a credential), give the sentence the agent should say
  and the link, together. A bare link from an agent reads as phishing.
- **A refusal is a contract.** Name the machine-readable code, whether it is
  terminal, and the one action that clears it.
- A skill covers its domain and says what it does not cover in its first
  paragraph, so a model does not route unrelated tasks to it.

## Deploy

The owner commits and pushes. On the host, `./deploy-skills.sh` pulls and runs
`web-ui/build.sh`; nginx serves `web-ui/public/` directly. `web-ui/nginx.conf`
is kept identical to the live site file and is applied by hand
(`cp` into `sites-enabled`, `nginx -t`, reload) — the deploy script does not
touch it.
